# Survey Form

A simple, responsive survey form built with HTML and CSS. The project demonstrates common form elements, basic client-side validation, and a clean, centered layout.

## Features

- Name input field
- Email input with built-in email validation
- Number input with minimum and maximum values
- Dropdown selection
- Radio button options
- Multiple checkbox selections
- Additional comments textarea
- Required field validation
- Responsive layout
- Styled submit button with hover effect

## Technologies Used

- HTML5
- CSS3

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Onunga123/survey-form.git
```

### Open the project

Navigate to the project directory:

```bash
cd survey-form
```

Open `index.html` in any modern web browser.

You can also double-click the file to open it directly.

## How to Use

1. Enter your name.
2. Enter your email address.
3. Provide a number between 1 and 100.
4. Select an option from the dropdown menu.
5. Choose one option using the radio buttons.
6. Select one or more checkboxes.
7. Add any additional comments.
8. Click **Submit**.

## Form Validation

The form includes built-in HTML validation for:

- Required fields
- Valid email addresses
- Numbers between 1 and 100
- Required radio button selection
- Required checkbox selection
